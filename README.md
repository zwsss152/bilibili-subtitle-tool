# 视频 / 播客转文字稿工具（B 站 / 抖音 / 机核 · 本地版）

一个带 GUI 窗口的本地工具，用来把视频、播客里「说了什么」变成可读的文字稿。支持 B 站、抖音和机核网播客。

## 它能做什么

1. **提取 CC 字幕**：粘贴 B 站视频链接 / BV 号 / av 号，自动抓取视频的字幕（UP 主上传的或平台 AI 生成的字幕）。
2. **无字幕也能用**：没有 CC 字幕的视频（比如字幕是「烧」在画面里的硬字幕），可选「本地语音识别」——一键下载音频后用 faster-whisper 在本机离线转写，全程不联网、不上传任何内容。
3. **抖音支持**：抖音没有官方字幕体系，直接走「下载音频 → 本地语音识别」流程。
4. **机核播客支持**：粘贴机核电台链接（`gcores.com/radios/xxxxxx`），直接取官方音频转文字稿——播客动辄一两小时，很适合先转成文字再挑着听或写稿引用。
5. **两种视图**：带时间轴的原文（`[02:35] 内容`）和按说话停顿分段的纯文本，方便通读。
6. **导出**：一键复制全部，或导出为 `.txt`。

> 一句话：你想知道视频/播客里说了什么，它就把那段话给你扒下来。

## 关于「为什么我的视频没字幕」

在 B 站里你「看到的字」有两种：

- **CC 字幕**：可开关、独立存在的文字轨道，工具能直接提取（最准）。
- **硬字幕**：直接「烧」进画面的像素，是视频的一部分，服务器上没有文字数据，任何接口都取不到。

剪辑号 / 课程搬运视频几乎都是硬字幕，所以这类视频只能走「本地语音识别」。这是视频本身的字幕形式决定的，不是工具的问题。

## 使用方式

### 方式一：直接运行（推荐，已配好环境）

双击 `启动.bat` 即可打开窗口（项目内已带 `.venv` 隔离环境）。

### 方式二：自己装依赖运行

```bash
# 1. 创建并激活虚拟环境
python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # macOS / Linux

# 2. 安装依赖（仅语音识别需要）
pip install -r requirements.txt

# 3. 运行
python bilibili_subtitle_tool.py
```

## 操作流程

1. 粘贴链接 → 点「提取字幕」
2. 优先拿 CC 字幕（最准）
3. 没有 CC 字幕 → 弹窗询问是否启用本地语音识别
4. 确认后自动：下载音频（yt-dlp）→ 离线转写（faster-whisper）→ 展示带时间轴的文字

窗口底部有进度条和剩余时间提示，不会「不知道它在干嘛」。

## 语音识别模型

- 界面可选 `tiny / base / small / medium`，默认 `small`。中文讲解视频建议 `small` 或更大，越大越准但越慢。
- **首次使用会下载模型**（默认 `small` 约 480MB，走国内镜像，只下一次），之后完全离线。
- 识别速度取决于视频时长与你的 CPU；有 NVIDIA 显卡会快很多。

## 合规与风控

- 本工具仅本地运行、仅供个人学习整理使用。
- 已内置请求限速（间隔 1.2 秒），请勿频繁 / 批量抓取。
- 请遵守 bilibili / 抖音 / 机核用户协议与相关版权法规，勿传播他人受版权保护的内容。
- 识别结果可能有个别错字（尤其是口音重、背景音吵、专业术语多的情况），请自行核对。

## B 站 Cookie 到底有没有用？

**结论：多数情况下不需要填；只有遇到「登录才有字幕」的视频时它才起作用。**

具体来说，B 站的字幕（`player/wbi/v2` 接口）分两种可见性：

| 场景 | 不带 Cookie | 带 Cookie |
| --- | --- | --- |
| UP 主上传的公开字幕 | ✅ 能取到 | ✅ 能取到 |
| 平台 AI 生成字幕（未登录也可见） | ✅ 能取到 | ✅ 能取到 |
| 需要登录才可见的字幕 / 部分受限视频 | ❌ 取不到，接口返回空 → 自动降级为本地语音识别 | ✅ 能取到 |
| 高码率音频下载（极端情况） | ✅ 一般可以 | ✅ 更稳 |

所以它的定位是**「兜底增强」**而不是必需项：不填，工具照样跑，只是偶尔会多走一遍语音识别（慢但结果一样准）；填了，命中率更高、少做无用功。

怎么拿：浏览器登录 B 站 → F12 → Network → 刷新页面 → 随便点一个 `bilibili.com` 的请求 → 复制 Request Headers 里的 `Cookie:` 整行（很长，含 `SESSDATA`、`bili_jct` 等）→ 勾选工具里的「B 站 Cookie（可选）」粘贴进去即可。

> 注意：Cookie 等于你的登录凭证，只在本机使用、不要发给别人。工具本身不会上传或保存它。

## 批量转写工具（batch_transcriber.py）

写文章收集资料专用：双击 `批量转写.bat`。

- **队列式批量处理**：随时粘贴链接随时入队（支持一次粘贴多条，空格/换行分隔；抖音分享口令整段粘贴也能识别），自动逐条处理，无需逐一手动操作。
- **多平台混排**：B 站、抖音、机核播客链接可以混在同一个队列里，各走各的最优路径。
- **主题文件夹**：先填主题名点「创建/使用该主题」，该主题下所有文字稿自动存入 `文字稿/<主题>/`，多分 P 视频自动逐 P 出稿（`标题_P1.txt`…）。
- **全自动无确认**：B 站优先 CC 字幕（秒出），无字幕自动下载音频转本地识别；机核直接取官方音频直链；单页/单条失败只记该条并继续，下载失败自动重试一次。
- **提速**：批处理推理 + 模型常驻 + 下载/识别双线程并行。实测（15 分钟音频，CPU）：旧方案 146.6s → 均衡模式 68.7s（2.1 倍）→ 极速模式 40.3s（3.6 倍）。
- **输出规范**：统一简体中文（opencc 繁转简）、中文语境标点自动转全角、自动清理识别「重复幻觉」（长音频里 whisper 偶尔会卡在解码循环刷出一长串重复字/短语，已做收敛）、按说话停顿与句末标点分段、每段带起始时间戳便于引用。

### 各平台链接格式

| 平台 | 可粘贴的内容 | 示例 |
| --- | --- | --- |
| B 站 | 视频链接 / BV 号 / av 号 | `https://www.bilibili.com/video/BV1xx411c7mD` |
| 抖音 | 分享链接或整段分享口令 | `https://v.douyin.com/xxxxxxx/` |
| 机核 | 电台节目链接 | `https://www.gcores.com/radios/196305` |

## 技术说明

- CC 字幕获取：B 站 `view` / `player/v2`（wbi 签名）接口，纯标准库。
- 音频下载：B 站 / 抖音走 yt-dlp（只下音轨）；机核走官方开放接口 `gapi/v1/radios/{id}?include=media` 取音频文件名，拼出阿里云 OSS 直链后流式下载（支持断点续传）。
- 离线转写：faster-whisper（OpenAI Whisper 加速版），纯本机 CPU 运算。

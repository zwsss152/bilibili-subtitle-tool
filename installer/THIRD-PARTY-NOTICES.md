# Third-party components

This distribution includes Python, Tcl/Tk, Pillow, PyAV/FFmpeg, imageio-ffmpeg,
OpenCC (Python reimplementation), pypinyin, yt-dlp, pywebview, pythonnet,
clr-loader, cffi, and the PyInstaller bootloader. Their original license files
and package metadata are retained in the application bundle where supplied.

Python: https://www.python.org/psf/license/
PyInstaller bootloader exception: https://pyinstaller.org/en/stable/license.html
FFmpeg: https://ffmpeg.org/legal.html
imageio-ffmpeg: https://github.com/imageio/imageio-ffmpeg
PyAV: https://github.com/PyAV-Org/PyAV
pywebview: https://github.com/r0x0r/pywebview
yt-dlp: https://github.com/yt-dlp/yt-dlp

The included Microsoft Edge WebView2 Evergreen Standalone Installer is an
unmodified Microsoft-signed redistributable, subject to Microsoft's terms:
https://developer.microsoft.com/en-us/microsoft-edge/webview2/

Cloud inference is provided separately by Alibaba Cloud and requires the
end user's own credentials. No API key or personal data is included.
